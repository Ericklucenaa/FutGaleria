# Instalação no Google Chrome (Windows, Linux e macOS)

1. Abra **Releases** neste repositório.
2. Quando houver publicação, em **Assets**, baixe `FUT-Galeria-vX.Y.Z-Chrome.zip`. **Não** use o arquivo automático `Source code (zip)` do GitHub.
3. Extraia o arquivo em uma pasta que não será movida.
4. Abra `chrome://extensions`.
5. Ligue **Modo do desenvolvedor**.
6. Clique em **Carregar sem compactação**.
7. Selecione **FutGaleria_Chrome** (pasta com o arquivo `manifest.json`).
8. Clique em **Detalhes → Opções da extensão** para configurar idioma e licença quando disponíveis.

## Atualização

Baixe a nova versão da Release, faça backup, substitua o conteúdo da pasta usada na instalação e clique **Recarregar** no Chrome. Atualizações do GitHub não são instaladas automaticamente. Não apague dados do navegador nem altere arbitrariamente a pasta se quiser preservar a instalação anterior.

## Segurança

Instalar extensões não verificadas requer confiança na origem; confira se está no repositório oficial anunciado pelo desenvolvedor. Não compartilhe senhas, cookies, chaves de acesso ou arquivos pessoais com quem se oferecer para instalar.

A extensão realiza ações automatizadas que podem violar regras da EA; use essas informações antes de decidir instalar.
