# Perguntas frequentes

### Por que o GitHub mostra `Source code (zip)`?
É o código/arquivos do **repositório público de documentação**, gerado automaticamente pelo GitHub. Para instalar a extensão, baixe o ZIP anexado manualmente em **Assets** de uma Release publicada.

### O FREE tem quantas galerias?
A versão 1.3.1 limita o FREE a **cinco** galerias. O PRO prevê galerias ilimitadas.

### O PRO é ativado apenas por baixar do GitHub?
Não. O cliente precisa de uma licença válida, conferida pelo servidor quando o sistema comercial estiver em funcionamento.

### Tenho atualizações automáticas?
Não, a instalação manual a partir de ZIP exige acompanhar as novas Releases e atualizar os arquivos localmente.

### Por que a licença não ativa?
A infraestrutura comercial ainda está pendente. Quando ativada, verifique conectividade, servidor e suporte. Não compartilhe a chave em Issues públicas.

### O GitHub evita banimentos da EA?
Não. A EA proíbe automação e compradores automáticos no Ultimate Team. Disponibilizar a extensão fora da Chrome Web Store não resolve isso.
